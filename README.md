TasHu’S Maditation — Smart Crochet Companion

A mobile app UI design for crochet lovers, built as a single-file interactive HTML prototype. It has 20 screens in a 393 × 852 phone frame and uses a soft rose-pink, 3D-style, glassmorphism look inspired by the TasHu’S Maditation logo.

Live Demo

https://tashu-26.github.io/TasHu-S-Maditation-Mobile-app-ui/

Features
Splash, onboarding, sign in and create account
Home dashboard with current projects and quick actions
Pattern finder and pattern details
Yarn stash and add/edit yarn
My projects, project details and new project
Color combination helper (analogous, complementary, triadic)
Project cost calculator in Bangladeshi taka (৳)
Learn crochet lessons
Tutorial simplifier (input, loading, result, invalid link, unsupported link and failed states)
My studio, saved items and settings
How to Run
Download or clone this repository.
Open index.html in any modern browser (Chrome, Edge, Firefox or Safari).

No installation or internet connection is needed, apart from loading the Nunito font.

Tech
HTML, CSS and JavaScript (no frameworks)
Glassmorphism using backdrop-filter
Yarn illustrations drawn with CSS
